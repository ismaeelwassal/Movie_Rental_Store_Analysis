# 🎬 Movie Rental Store Analysis (Power BI & SQL Project)

## 📌 Overview
This project analyzes a movie rental store dataset using Power BI to extract business insights and visualize key performance metrics such as revenue, customer behavior, and movie popularity.

---

## 📊 Dashboard Insights
- Total revenue from rentals
- Most rented movie categories
- Top performing movies
- Customer rental behavior
- Monthly rental trends

---

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- MY SQL
- Excel / CSV Dataset

---

## 📈 Features
- Interactive dashboard
- KPI cards (Revenue, Rentals, Customers)
- Trend analysis
- Category breakdown
- Filters for dynamic exploration
